# LARPOS

> The operating system for people who say "I use Arch btw" and "my opsec is crazy" in the same breath.

A fake hacker terminal. **Pure parody**: it scans nothing, hacks nothing, looks nothing up, and "doxxes" only a cat named Mr. Whiskers.

## Run it

**Windows 10/11** (no install): double-click `LARPOS.bat`.
If SmartScreen complains, click *More info -> Run anyway*. The script is plain text, read it first if you like.

**Mac / Linux** (bash): 

    chmod +x larpos.sh
    ./larpos.sh

Keep the `assets` folder next to the script.

## The main event

    sudo apt install opsec arch linux hello world print

Don't say we didn't warn you.

## Commands

Type `cmds` inside LARPOS for the full list. Highlights: `neofetch`, `nmap`, `doxx <name>`, `vpn`, `tor`, `opsec`, `hack`, `ping`, `feds`, `rm -rf /`.

Warning: the feds may show up at random. Flashing red/blue lights and beeping. Photosensitive folks, maybe skip.
